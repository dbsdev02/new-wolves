# Reports

Place the final report PDF here.

The gated download on the home page ("UAE Real Estate Market Sentiment Report
2026" section) links to:

    /reports/uae-real-estate-sentiment-report-2026.pdf

So the file must be named exactly:

    uae-real-estate-sentiment-report-2026.pdf

To change the filename or download name, edit
`frontend/src/components/home/MarketReportDownload.tsx` (REPORT_PDF /
REPORT_FILENAME constants).
